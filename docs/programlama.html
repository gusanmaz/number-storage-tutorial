Kodda Sayılar ve Bitler

Öğrendiklerini koda dökme zamanı. Bu bölümde sayıları farklı tabanlarda yazmayı, aralarında dönüştürmeyi ve tek tek bitlerle çalışmayı JavaScript ve Python’da göreceksin. (Kod örneklerinde dili üstteki sekmelerden seçebilirsin; seçimin tüm sayfada hatırlanır.)

Sayı yazımı (literal)

İki dilde de aynı ön ekler kullanılır. Hepsi aynı türden sıradan sayılar üretir; taban sadece yazılış biçimidir.

const a = 0b1010;      // binary  → 10
const b = 0o12;        // octal   → 10
const c = 0xA;         // hex     → 10
const d = 10;          // decimal → 10
console.log(a === b && b === c && c === d);   // true

const milyon = 1_000_000;   // alt çizgi okunabilirlik içindir, değeri etkilemez
const maske  = 0b1111_0000;

Dönüşüm fonksiyonları

const n = 255;
// sayı → metin
n.toString(2);                    // "11111111"
n.toString(16);                   // "ff"
n.toString(16).toUpperCase();     // "FF"
n.toString(2).padStart(16, "0");  // "0000000011111111"

// metin → sayı
parseInt("11111111", 2);          // 255
parseInt("ff", 16);               // 255
parseInt("0xFF");                 // 255  (0x ön ekini tanır)
Number("0b1010");                 // 10   (Number tüm ön ekleri tanır)

n = 255
# sayı → metin
bin(n)              # '0b11111111'
hex(n)              # '0xff'
oct(n)              # '0o377'
format(n, "b")      # '11111111'  (ön eksiz)
f"{n:08b}"          # '11111111'  8 haneye tamamla
f"{n:04X}"          # '00FF'      büyük harf hex, 4 hane
f"{n:#x}"           # '0xff'

# metin → sayı
int("11111111", 2)  # 255
int("ff", 16)       # 255
int("0xff", 0)      # 255  (taban 0 = ön ekten anla)

Konsol: bir sayı yaz, iki dilde gör

Ondalık, 0x…, 0b…, 0o… ya da negatif bir tamsayı yaz. (Burada eval kullanılmaz; yazdığın sadece sayı olarak ayrıştırılır.)

Bit operatörleri

Bit operatörleri iki sayının aynı konumdaki bitlerini tek tek işler. Kural tablosu:

aba & b (VE)a | b (VEYA)a ^ b (ÖZEL VEYA)
00000
01011
10011
11110

~a (DEĞİL) tüm bitleri ters çevirir. a << n bitleri n kez sola kaydırır (× 2ⁿ), a >> n sağa kaydırır (÷ 2ⁿ, aşağı yuvarlayarak).

Dile özgü tuzaklar

    

        

            
JavaScript

            
    
                
  • Tüm sayılar 64 bit double’dır. 2⁵³’ten büyük tamsayılar tam saklanamaz: 2**53 + 1 === 2**53 → true. Büyük tamsayılar için BigInt (123n).
    • 
                
  • Bit operatörleri sayıyı önce 32 bit işaretli tamsayıya çevirir: 1 << 31 → -2147483648. İşaretsiz sonuç için >>> 0.
    • 
                
  • (-5).toString(2) → "-101"; ikiye tümleyen görmek için (-5 >>> 0).toString(2).
    • 
                
  • parseInt("12px") → 12 ama Number("12px") → NaN.
    • 
            

        

        

            
Python

            
    
                
  • Tamsayılar sınırsızdır; taşma olmaz. Ama float yine 64 bit double’dır.
    • 
                
  • bin(-5) → '-0b101'. Python ikiye tümleyeni göstermez; 8 bitlik görüntü için bin(-5 & 0xFF) → '0b11111011'.
    • 
                
  • ~5 → -6 (çünkü ~x = −x − 1).
    • 
                
  • / her zaman float verir (7 / 2 = 3.5); tam bölme için //.
    •

Özet

        
    
            
  • Ön ekler: 0b binary, 0o octal, 0x hex. Hepsi aynı sayı türünü üretir.
    • 
            
  • JS: n.toString(taban), parseInt(metin, taban). Python: bin/hex/oct, format/f-string, int(metin, taban).
    • 
            
  • & (ikisi de 1), | (en az biri 1), ^ (farklıysa 1), ~ (tersle), << (× 2ⁿ), >> (÷ 2ⁿ).
    • 
            
  • Maske kalıpları: oku (x>>n)&1, aç x|(1<<n), kapat x&~(1<<n), çevir x^(1<<n).
    • 
        

    


    

        

            
0b1100 & 0b1010 sonucu nedir?

            
  • 0b1110 (14)
  • 0b1000 (8)
  • 0b0110 (6)
  • 0b0010 (2)

            
Sadece iki sayıda da 1 olan bit (en soldaki) 1 kalır.

        

        

            
5 << 3 kaçtır?

            
  • 8
  • 15
  • 53
  • 40

            
Sola 3 kaydırmak 2³ = 8 ile çarpmaktır: 5 × 8 = 40.

        

        

            
Python’da int("1F", 16) ne döndürür?

            
  • 31
  • "31"
  • 116
  • Hata

            
1 × 16 + 15 = 31 (sayı olarak).

        

        

            
x ^ x her zaman neye eşittir?

            
  • x
  • Tüm bitleri 1 olan sayı
  • 0
  • 2x

            
Aynı bitler XOR’lanınca hep 0 çıkar. (Assembly’de bir yazmacı sıfırlamanın klasik yolu.)

        

        

            
JavaScript’te 0.1 * 3 === 0.3 neden false’tur?

            
  • JavaScript’te bir hata var
  • Sayılar IEEE 754 double olduğu için 0,1 tam saklanamaz
  • === yerine == kullanılmalı
  • 0.3 bir metindir

            
Ondalıklı Sayılar bölümünü hatırla: 0.1 * 3 = 0.30000000000000004.
