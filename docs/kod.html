§ 11.1Sayıları kodda yazmak

Kodda 255, 0xFF, 0o377 ve 0b11111111 yazmak arasında hiçbir fark yoktur: dördü de bellekte aynı bit desenine dönüşür. Bunlara sayı sabitleri (literal) denir. Ön ek, derleyiciye yalnızca “bu rakamları hangi tabanda okuyayım?” sorusunun cevabını verir. Taban, değişkende saklanmaz.

§ 11.2Diller tamsayıları farklı saklar

Bölüm 3’te sabit genişlikli kutuların taşabileceğini, Bölüm 6’da double’ın 253’ten sonra tamsayıları atladığını gördük. Diller bu sınırlarla farklı şekillerde başa çıkar:

  • C, Java, Go: int8, int32, uint64… Sabit genişlik, taşınca başa sarar.
  • Python: int sınırsızdır. Sayı büyüdükçe Python ona daha fazla byte ayırır; 2**1000 sorunsuz hesaplanır. Bedeli: biraz yavaşlık.
  • JavaScript: Her number bir double’dır. Tamsayılar 253 − 1’e kadar güvenlidir (Number.MAX_SAFE_INTEGER). Daha büyükler için sonuna n eklenen BigInt var: 2n ** 100n. Ve bir sürpriz: bit işlemleri sayıyı geçici olarak 32 bitlik işaretli tamsayıya çevirir.

§ 11.4Maskeler ve bayraklar

Bir byte’ı 8 ayrı evet/hayır anahtarı olarak kullanabiliriz. Her bite bir anlam veririz (bunlara bayrak denir) ve bit işlemleriyle tek tek okur ya da değiştiririz. En bilinen örnek Unix dosya izinleri: sahibi, grubu ve diğerleri için okuma (r), yazma (w) ve çalıştırma (x). 9 bit; üçerli gruplandığı için sekizli yazılır. chmod 755 komutundaki 755 tam olarak budur.

Dört temel kalıbı ezberlemeye değer:

OKU, YAZ, CALISTIR = 0b100, 0b010, 0b001   # 4, 2, 1

izin = OKU | YAZ               # bayrak eklemek (OR)      → 0b110
if izin & YAZ:                 # bayrak kontrolü (AND)
    print("yazılabilir")
izin &= ~YAZ                   # bayrak kaldırmak (AND NOT) → 0b100
izin ^= CALISTIR               # bayrak çevirmek (XOR)    → 0b101

renk = 0xFF8800
yesil = (renk >> 8) & 0xFF     # alan çıkarmak: kaydır + maskele → 136

const OKU = 0b100, YAZ = 0b010, CALISTIR = 0b001;

let izin = OKU | YAZ;           // ekle
if (izin & YAZ) console.log("yazılabilir");
izin &= ~YAZ;                   // kaldır
izin ^= CALISTIR;               // çevir

const tekMi = (n) => (n & 1) === 1;      // son bit 1 ise tek
const ikininKuvvetiMi = (n) => n > 0 && (n & (n - 1)) === 0;

§ 11.5Değişken bir kutu mu, bir etiket mi?

Bölüm 10’da değişken adının bir adresin takma adı olduğunu söyledik. C’de bu tam olarak doğru: int a bir kutudur ve b = a kutunun içindeki byte’ları kopyalar. Python ve JavaScript’te ise hikâye biraz farklı ve pek çok hatanın kaynağı burası.

Python’da her değer bir nesnedir ve bellekte kendi yerinde yaşar. Değişken ise o nesneye yapıştırılmış bir etikettir. b = a yeni bir nesne yaratmaz; aynı nesneye ikinci bir etiket yapıştırır. JavaScript’te sayı, metin ve boolean gibi ilkel değerler doğrudan kopyalanır; diziler ve nesneler ise Python’daki gibi referansla paylaşılır.

Değiştirilemez (immutable): Python’da int, float, str, tuple; JavaScript’te bütün ilkel türler. Paylaşılmaları güvenlidir; “değiştirmek” her zaman yeni bir değer üretir.

Değiştirilebilir (mutable): list, dict, set ve JavaScript’te diziler ve nesneler. Paylaşılan bir nesneyi yerinde değiştirmek, onu gösteren bütün adları etkiler.

Kimlik ile eşitlik farklı sorulardır. == “içerikleri aynı mı?”, Python’daki is ise “aynı nesne mi?” diye sorar. CPython’da id(x), nesnenin bellekteki adresidir; Bölüm 10’la bağlantı tam burada.

a = [1, 2, 3]
b = a              # aynı nesne
c = a[:]           # yeni nesne, aynı içerik (sığ kopya)
print(a == c, a is c)     # True False
print(a is b)             # True
print(hex(id(a)))         # '0x7f3a2c1d4e80' gibi: bir adres!

def ekle(liste):
    liste.append(99)      # çağıranın listesini değiştirir!
ekle(a); print(b)         # [1, 2, 3, 99]

import copy
m = [[0, 0], [0, 0]]
s = m.copy()              # sığ: iç listeler paylaşılıyor
d = copy.deepcopy(m)      # derin: her şey yeni
m[0][0] = 7
print(s[0][0], d[0][0])   # 7 0

const a = [1, 2, 3];
const b = a;               // aynı dizi
const c = [...a];          // yeni dizi (sığ kopya)
console.log(a === c, a === b);  // false true

a.push(4);                 // const ama değişebilir!
// a = [];                 // TypeError: const atama yasak

let x = 10, y = x;         // ilkel: değer kopyalanır
y++;
console.log(x, y);         // 10 11

const m = [[0, 0], [0, 0]];
const s = [...m];                    // sığ
const d = structuredClone(m);        // derin
m[0][0] = 7;
console.log(s[0][0], d[0][0]);       // 7 0

const (JavaScript) adın başka bir nesneye taşınmasını yasaklar; nesnenin içinin değişmesini değil. Bir listeyi bir fonksiyona verdiğinde ya da başka bir değişkene atadığında kopyasını değil, kendisini paylaşırsın. Kopya istiyorsan açıkça yap.

Küçük sayıların sırrıCPython −5 ile 256 arasındaki tamsayıları önceden yaratır ve tekrar tekrar kullanır. Bu yüzden a = 256; b = 256; a is b doğru çıkabilirken aynı şey 257 için yanlış olabilir. Ders: sayıları ve metinleri is ile değil, == ile karşılaştır. is’i sadece None için kullan.
