Hex Renk Kodları

RGB matematiği ve p5.js'te renk kullanımı

RGB Renk Modeli

Ekranlarda renkler üç temel rengin karışımıyla oluşturulur: Kırmızı (R), Yeşil (G) ve Mavi (B).

Her kanal: 0-255 arası (1 byte = 2 hex rakamı)
Toplam: 256 × 256 × 256 = 16,777,216 renk

Hex Renk Formatı

Format: #RRGGBB
1#FF5733
2  ││││││
3  ││││└┴── Blue:  33₁₆ = 51₁₀
4  ││└┴──── Green: 57₁₆ = 87₁₀
5  └┴────── Red:   FF₁₆ = 255₁₀

İnteraktif: Renk Oluşturucu

p5.js'te Renk Kullanımı

p5.js, Processing tabanlı bir JavaScript kütüphanesidir. Renkleri çeşitli şekillerde tanımlayabilirsiniz:

p5.js - Renk Tanımlama Yöntemleri
1// Hex string ile
2fill("#FF5733");
3stroke("#00FF00");
4background("#1a1a2e");
5
6// RGB değerleri ile (0-255)
7fill(255, 87, 51);         // R, G, B
8fill(255, 87, 51, 128);    // R, G, B, Alpha
9
10// Gri tonları (tek değer)
11fill(128);                  // Gri (R=G=B=128)
12fill(128, 200);             // Gri + Alpha
13
14// color() fonksiyonu ile
15let turuncu = color("#FF5733");
16let mavi = color(0, 100, 255);
17fill(turuncu);
p5.js - Renk Bileşenlerini Alma
1let c = color("#FF5733");
2
3// Bileşenleri çıkar
4let r = red(c);     // 255
5let g = green(c);   // 87
6let b = blue(c);    // 51
7let a = alpha(c);   // 255 (varsayılan)
8
9// Parlaklık ve doygunluk
10let parlaklik = brightness(c);  // 0-100
11let doygunluk = saturation(c);  // 0-100
12let ton = hue(c);              // 0-360

Temel Renkler ve Karışımları

Renk Hex RGB Açıklama
#FF0000 255, 0, 0 Saf Kırmızı
#00FF00 0, 255, 0 Saf Yeşil
#0000FF 0, 0, 255 Saf Mavi
#FFFF00 255, 255, 0 Sarı (R + G)
#FF00FF 255, 0, 255 Magenta (R + B)
#00FFFF 0, 255, 255 Cyan (G + B)
#FFFFFF 255, 255, 255 Beyaz (Hepsi max)
#000000 0, 0, 0 Siyah (Hepsi min)

Hex → RGB Dönüşümü

Manuel Hesaplama: #FF5733
1// Her 2 hex rakamını decimal'e çevir
2
3Red:   FF₁₆ = 15×16 + 15×1 = 240 + 15 = 255
4Green: 57₁₆ = 5×16 + 7×1  = 80 + 7   = 87
5Blue:  33₁₆ = 3×16 + 3×1  = 48 + 3   = 51
6
7// Sonuç
8#FF5733 = RGB(255, 87, 51)

Alfa Kanalı (Şeffaflık)

RGBA formatında dördüncü değer şeffaflığı belirler:

p5.js - Alfa Kullanımı
1// Alpha: 0 (şeffaf) - 255 (opak)
2fill(255, 0, 0, 255);   // Tam opak kırmızı
3fill(255, 0, 0, 128);   // %50 şeffaf kırmızı
4fill(255, 0, 0, 50);    // Çok şeffaf kırmızı
5
6// 8 karakterli hex (RRGGBBAA)
7fill("#FF000080");      // 80₁₆ = 128₁₀ = %50

Gri Tonları

R = G = B olduğunda renk gridir:

#000#333#666#999#CCC#FFF
p5.js - Gri Tonları
1// Tek değer = gri (R=G=B)
2fill(0);       // Siyah
3fill(128);     // Orta gri
4fill(255);     // Beyaz
5
6// Hex'te tekrarlı rakamlar
7fill("#888");  // = #888888
8fill("#AAA");  // = #AAAAAA
Özet
• Hex renk = #RRGGBB (6 karakter = 3 byte = 24 bit)
• Her kanal: 00-FF (0-255)
• 256³ = 16,777,216 renk kombinasyonu
• Gri için: R = G = B
