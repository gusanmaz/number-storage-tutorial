Memory ve Veri Saklama

Veriler bellekte nasıl saklanır? Adresler neden hex?

Memory Adresleri Neden Hexadecimal?

Bilgisayarın RAM'inde her byte'ın benzersiz bir adresi vardır. Bu adresler hexadecimal olarak gösterilir çünkü:

📏 Kompakt

32-bit adres:
Binary: 32 karakter
Hex: sadece 8 karakter

🔍 Okunabilir

Her 2 hex = 1 byte
Byte sınırları kolayca görülür

🔄 Kolay Dönüşüm

Hex ↔ Binary
Her hex = 4 bit

Aynı Adres, Farklı Gösterimler
1// 32-bit memory adresi
2
3Binary:  01111111111111100100001010100000  (32 karakter!)
4Hex:     0x7FFE42A0                        (8 karakter)
5Decimal: 2147369632                        (okunması zor)

Memory Görselleştirmesi

Aşağıda bir bellek bölgesinin nasıl göründüğünü görüyorsun. Her satır 8 byte, her hücre 1 byte (2 hex rakamı).

Yukarıdaki Memory'de Ne Var?

Mavi: 255 sayısı (4 byte int: 0x000000FF)
Yeşil: Bir pointer/adres (0x7FFFE000)

ASCII: Karakterlerin Sayısal Karşılığı

Bilgisayar karakterleri sayı olarak saklar. ASCII (American Standard Code for Information Interchange) tablosu, her karaktere 0-127 arası bir sayı atar (7 bit, 1 byte'a sığar).

Kontrol Karakterleri (0-31): Non-Printable

Non-Printable Karakterler Neden Var?
ASCII, 1960'larda teletype (yazı makinesi) ve terminal cihazları için tasarlandı. İlk 32 karakter (0-31) ekrana yazılmaz, bunun yerine cihazı kontrol eder:

• Metin biçimlendirme: Yeni satır, sekme, sayfa sonu
• İletişim kontrolü: Başlangıç/bitiş sinyalleri, onay
• Cihaz kontrolü: Zil çalma, silme, iptal

Bugün çoğu kullanılmıyor ama \n, \t, \r hâlâ çok önemli!

Unicode: ASCII'nin Ötesi

ASCII sadece 128 karakter destekler - İngilizce için yeterli ama Türkçe'deki ş, ğ, ü veya Çince, Arapça karakterler için Unicode gerekir.

UTF-16 2 veya 4 byte JavaScript ve Windows içinde kullanılır
UTF-32 4 byte (sabit) Her karakter 4 byte, basit ama verimsiz

Null Terminator (\0) Neden Önemli?

C dilinde string'ler \0 (null) karakteriyle biter. Bu karakter string'in nerede bittiğini belirtir.

C Syntax Açıklaması
• char str[] → karakter dizisi (string) tanımla
• strlen(str) → string'in uzunluğunu döndürür (Python'daki len() gibi)
• sizeof(str) → değişkenin bellekte kapladığı byte sayısı

Tehlike: Null Olmadan Ne Olur?
Eğer string'in sonunda \0 yoksa, program string'in nerede bittiğini bilemez. Bellekte rastgele veri okumaya devam eder (buffer overflow). Bu, güvenlik açıklarına ve program çökmelerine yol açar.

Ondalıklı Sayılar: IEEE 754

Ondalıklı sayılar (float, double) tamamen farklı bir formatta saklanır: IEEE 754. Bu format sayıyı üç parçaya ayırır. Önce elle bir örnek yapalım:

Örnek: 6.75 Sayısını IEEE 754'e Çevirelim

Adım 1: Tam ve Kesir Kısmı Ayır

6.75 → Tam kısım: 6, Kesir kısım: 0.75

Adım 2: Tam Kısmı Binary'ye Çevir

6 ÷ 2 = 3 kalan 0
3 ÷ 2 = 1 kalan 1
1 ÷ 2 = 0 kalan 1
Aşağıdan yukarı oku: 110

Adım 3: Kesir Kısmı Binary'ye Çevir

Kesri 2 ile çarp, tam kısmı al:
0.75 × 2 = 1.50 → 1
0.50 × 2 = 1.00 → 1
0.00 → dur
Yukarıdan aşağı oku: .11

Adım 4: Binary Sayıyı Birleştir

6.75 = 110.11 (binary)

Adım 5: Normalize Et (Bilimsel Gösterim)

110.11 = 1.1011 × 22
(Noktayı sola kaydır, her kaydırmada üs +1)

Adım 6: IEEE 754 Parçalarını Çıkar

Sign (İşaret) Pozitif → 0
Exponent (Üs) Üs = 2, Bias = 127 → 2 + 127 = 129 → 10000001
Mantissa (Kesir) 1.1011 → baştaki 1 atılır → 10110000000000000000000

Sonuç

0 10000001 10110000000000000000000

Mantissa Neden "Baştaki 1" Atılır?
Normalize edilmiş her binary sayı 1.xxxx formatındadır (sıfır hariç). Baştaki 1 her zaman var olduğu için saklamaya gerek yok! Bu şekilde 1 bit tasarruf edilir ve mantissa'da daha fazla hassasiyet sağlanır. Buna "implicit 1" denir.

Pointer (İşaretçi): Adres Tutan Değişken

Pointer, başka bir değişkenin bellek adresini saklayan değişkendir. Pointer değeri de hex olarak gösterilir. C ve C++ dillerinde yaygın kullanılır.

C Dilini Bilmeyenler İçin
• int x → x adında bir tam sayı değişkeni tanımla
• int *ptr → ptr adında, int'e işaret eden bir pointer tanımla
• &x → x'in bellek adresini al (& = "adresi")
• *ptr → ptr'nin gösterdiği adresteki değeri al (* = "değeri")
• printf() → ekrana yazdır (Python'daki print gibi)
int x
42
@ 0x7FFE0008
←
int *ptr
0x7FFE0008
@ 0x7FFE0010

ptr değişkeni, x'in adresini tutuyor. Bu adres üzerinden x'e erişebiliriz.

C'de Pointer Kullanımı (Açıklamalı)
1int x = 42;           // x adında değişken, değeri 42
2int *ptr = &x;        // ptr = x'in adresi (&x)
3
4printf("%d\n", x);      // x'in değeri: 42
5printf("%p\n", &x);    // x'in adresi: 0x7ffe0008
6printf("%p\n", ptr);   // ptr'nin tuttuğu adres: 0x7ffe0008
7printf("%d\n", *ptr);  // ptr'nin gösterdiği değer: 42
Python/JS Karşılığı
Python ve JavaScript'te pointer yoktur, ama referanslar benzer çalışır:
liste1 = [1, 2, 3]
liste2 = liste1 → liste2, liste1 ile aynı bellek adresine "işaret eder"

Referans vs Pointer (C++ için - Bilgi Amaçlı)

C++ dilinde hem pointer hem de referans kavramı vardır. İkisi de dolaylı erişim sağlar ama farklı davranırlar:

Özellik Pointer (*) Referans (&)
Null olabilir mi? Evet (hiçbir şeye işaret etmeyebilir) Hayır (her zaman bir şeye bağlı)
Başka şeye atanabilir mi? Evet (farklı adresi gösterebilir) Hayır (ilk atamadan sonra sabit)
Aritmetik yapılabilir mi? Evet (ptr++, ptr+5) Hayır
Kullanım *ptr ile değere eriş Doğrudan kullan (r gibi)
Python/JS ile Karşılaştırma
Python ve JavaScript'teki değişkenler referans gibi davranır - hepsi arka planda bir adrese işaret eder. Ama C++'taki pointer gibi doğrudan adres manipülasyonu yapamazsınız - bu daha güvenli ama daha az kontrol sağlar.

Python ve JavaScript'te Referanslar

Hem Python hem JavaScript'te değişkenler aslında değerlere birer referans (adres) tutar. Ama bazı türler değiştirilebilir (mutable), bazıları değiştirilemez (immutable/primitive).

Python'da Mutable vs Immutable

✅ Immutable (Değiştirilemez)

• str (string)

• frozenset
• bool

⚠️ Mutable (Değiştirilebilir)

• list - değiştirilebilir dizi

• set - küme
• class nesneleri
• bytearray

JavaScript'te Primitive vs Reference Türler

JavaScript'te kavramlar biraz farklı: primitive (ilkel) ve reference (referans) türler.

Python vs JavaScript Farkı
• Python'da tuple var (immutable liste), JavaScript'te yok
• JavaScript'te undefined var, Python'da yok (None farklı)
• Python'da her şey nesne, JS'de primitive'ler nesne değil

✅ Primitive (İlkel Türler)

• number (42, 3.14)
• string ("merhaba")
• boolean (true/false)
• undefined (tanımsız)
• null (boş)
• symbol, bigint

⚠️ Reference (Referans Türleri)

• Object ({key: value})
• Array ([1, 2, 3])
• Function
• Date, Map, Set
• Tüm class instance'ları

JavaScript - Primitive vs Reference
1// PRIMITIVE: Değer kopyalanır

6
7// REFERENCE: Adres kopyalanır (aynı nesne!)

10arr1.push(4);

12
13// Gerçek kopya yapmak için:

16let obj2 = {...obj1};         // object için spread
17let deep = JSON.parse(JSON.stringify(obj)); // derin kopya
