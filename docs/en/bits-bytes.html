Bits & Bytes

Perhaps the most used formula in computer science: n bits give 2ⁿ different values. In this chapter you will see why it is true and learn to calculate data sizes correctly.

⏱ ~25 minPrerequisites: Binary, Hex
By the end of this chapter you will
  • calculate how many values n bits can represent, and their range;
  • find the minimum number of bits needed to encode a given number of things;
  • distinguish bit, nibble, byte and word;
  • explain the difference between KB and KiB, and why a 500 GB disk shows up as 465 GB.

A byte being 8 bits is not a law of nature; it is a standard that spread in the 1960s with the IBM System/360. 8 bits are enough for a character, split evenly into two hex digits, and are a power of two, which suits hardware. The byte is the smallest addressable unit of memory: you cannot address a single bit directly.

The key formula: n bits = 2ⁿ values

Each bit offers two options. Add a second bit and for each state of the first there are again two options: 2 × 2 = 4. A third bit doubles that again: 8. In other words, every new bit doubles the number of possibilities.

Add a bit, double the possibilities

Press “Add a bit”: one copy of the current list gets a leading 0, the other a leading 1. The list doubles every time.

n bits → 2ⁿ values  ·  unsigned range: 0 … 2ⁿ − 1 The largest value is 2ⁿ − 1 because counting starts at 0. 8 bits: 256 values, 0 … 255.

Quick conversion rules

bits = bytes × 8  ·  bits = hex digits × 4  ·  bytes = hex digits ÷ 2

In the real world: 32 bits and the 4 GB limit

A 32-bit processor can form 2³² different memory addresses. Since each address points to one byte, it can directly address at most 2³² bytes = 4 GiB. That is why 32-bit Windows couldn’t use more than 4 GB of RAM and the world moved to 64-bit. (2⁶⁴ bytes = 16 EiB — far, far beyond today’s computers.)

The reverse question: how many bits?

In everyday programming the question usually comes the other way round: “How many bits do I need to encode N different things?” The answer is the smallest n with 2ⁿ ≥ N (in maths: ⌈log₂ N⌉).

How many bits are enough?

Think first

The English alphabet has 26 letters. How many bits do you need for uppercase letters only? For upper and lower case together?

Show answer

26 letters: 2⁴ = 16 < 26 ≤ 32 = 2⁵ → 5 bits. Upper + lower = 52: 2⁵ = 32 < 52 ≤ 64 = 2⁶ → 6 bits. Add digits and punctuation and you reach 7 bits — which is exactly what ASCII uses (128 characters).

Data units: KB or KiB?

There is genuine confusion here. Because computers work in powers of two, “kilo” was long taken to mean 1024. But in the SI system “kilo” always means 1000 (kilometre, kilogram). To resolve the clash, in 1998 the IEC defined binary prefixes: kibi (Ki), mebi (Mi), gibi (Gi)…

Common mistake: mixing up bits and bytes

Internet speeds are measured in bits (Mbps, lowercase b), file sizes in bytes (MB, uppercase B). A 100 Mbps connection downloads at most 100 ÷ 8 = 12.5 MB per second.

Summary

  • 1 byte = 8 bits = 2 hex digits. The byte is the smallest addressable unit of memory.
  • n bits → 2ⁿ distinct values; unsigned range 0 … 2ⁿ − 1.
  • Encoding N values needs at least ⌈log₂ N⌉ bits (the smallest n with 2ⁿ ≥ N).
  • kB/MB/GB = powers of 1000; KiB/MiB/GiB = powers of 1024.
  • Network speed is in bits/s, file size in bytes: a factor of 8.

  • 5
  • 40

2⁵ = 32 is not enough, 2⁶ = 64 is → 6 bits.

If you add one more bit, what happens to the number of distinct values?

  • It increases by 1
  • It doubles
  • It increases by 8
  • It is squared
2ⁿ⁺¹ = 2 × 2ⁿ. Every new bit doubles the possibilities.

How many bytes is 1 GiB?

  • 1,000,000,000
  • 1,024,000,000
  • 1,000,000,024
  • 1,073,741,824
1 GiB = 2³⁰ = 1024 × 1024 × 1024 = 1,073,741,824 bytes.
