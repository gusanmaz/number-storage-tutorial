Chapter 7

Color, image and sound

A photo or a song is also just numbers in the end. But the colors and sounds of the world are continuous, while a computer can only count whole numbers. The bridge between them: sampling and rounding.

Reading: ~35 minBefore: Chapters 2 and 3

§ 7.1Every color from three lights

The retina of your eye has three kinds of color sensors (cones), roughly sensitive to red, green and blue. Your brain works out every color you see from the ratio of those three signals. Screens exploit this loophole: every pixel is made of three tiny lights side by side. By adjusting their brightness we convince the eye it sees whatever color we want.

With one byte per channel, a color takes 3 bytes = 24 bits. That is 224 = 16,777,216 different colors. Considering that the human eye distinguishes a few million colors, 24 bits is enough for most purposes, which is why it is called “true color”.

§ 7.2#RRGGBB: the hex address of a color

On web pages and in design tools we write colors like #FF8800. Now we know what that is: three bytes written in hex. Since each byte is exactly two hex digits, the color code splits neatly into six: the first two are red, the middle two green, the last two blue.

  • Shorthand: #F80 = #FF8800. Every digit is doubled.
  • Transparency: #FF880080. The fourth byte is the “alpha” channel: 00 fully transparent, FF fully opaque, 80 half transparent. Such a color takes 4 bytes = 32 bits.
  • Grays: when all three channels are equal the color is gray: #000000 black, #808080 middle gray, #FFFFFF white. One byte is enough for gray, which is why black-and-white photos take a third of the space.

§ 7.4An image: a grid of numbers

A digital image is a grid of colored squares called pixels. Each pixel is a 3-byte color. To store the image in memory we lay the pixels out row by row, left to right. The image below is 16 × 16 pixels, enlarged. Tap a pixel.

Computing the size is easy: width × height × 3 bytes. A × pixel photo takes uncompressed. The photos on your phone are much smaller because they are compressed: PNG shortens repetitions without losing any information; JPEG throws away details the eye will not notice.

Paletted imagesThe GIF format stores 1 byte per pixel instead of 3. That byte is not a color but a position in a 256-color palette table. Another “agreement”: number → color. Very much like ASCII’s number → letter table.

§ 7.5Colors in code

When we store a color as a single 24-bit number, separating the channels is a bit operation: to get red, shift the number right by 16 bits and mask the last 8 bits. We will see bit operations in detail in Chapter 9.

const c = 0xFF8800;                 // orange, a single number
const r = (c >> 16) & 0xFF;         // 255
const g = (c >> 8) & 0xFF;          // 136
const b = c & 0xFF;                 // 0
const hex = "#" + c.toString(16).padStart(6, "0");   // "#ff8800"
document.body.style.background = hex;
document.body.style.color = "rgb(" + r + ", " + g + ", " + b + ")";

function setup() {
  createCanvas(200, 200);
  background("#1E1E2E");
  fill(255, 136, 0);              // r, g, b (0-255)
  ellipse(70, 100, 80);
  fill("#FF880080");               // half transparent with alpha
  ellipse(130, 100, 80);
  let c = color("#0E7C86");
  print(red(c), green(c), blue(c));  // 14 124 134
}

c = 0xFF8800
r, g, b = (c >> 16) & 0xFF, (c >> 8) & 0xFF, c & 0xFF
print(r, g, b)                         # 255 136 0
print("#{:02X}{:02X}{:02X}".format(r, g, b))   # #FF8800
print(bytes.fromhex("FF8800"))        # b'\xff\x88\x00'

§ 7.6Sound: counting a wave in the air

Sound is rapid wiggling of air pressure. A microphone turns that wiggling into a voltage, a curve that changes continuously over time. To store the curve the computer does two things:

  1. Sampling: it measures the curve a fixed number of times per second. On a CD that is 44,100 times a second: 44.1 kHz.
  2. Quantization: it rounds each measurement to the nearest whole number. On a CD every sample is a 16-bit signed integer between −32,768 and 32,767.

That strangeness is called aliasing. To capture a wave correctly you need at least two samples per oscillation: the sample rate must be more than twice the highest frequency (the Nyquist–Shannon theorem). The human ear hears up to roughly 20,000 Hz, which is why 44,100 Hz was chosen. Wagon wheels that seem to spin backwards in movies are the same effect: the camera takes 24 frame “samples” per second.

Sound size is easy to compute too: samples/second × bits/sample × channels. CD-quality stereo takes 44,100 × 16 × 2 = 1,411,200 bits per second. A -minute song is uncompressed. Formats like MP3 and AAC shrink that about tenfold by throwing away details the ear will not hear.

Color, image and sound follow the same recipe: chop something continuous into pieces (pixels, samples) and round each piece to a limited number of bits (color depth, bit depth). Quality comes from those two settings, and so does file size.

§ 7.7Try it yourself

What color is #00FF00?

  • Red
  • Blue
  • Green
  • White
The middle byte is the green channel; at full power, the others zero.

Why is #FFFF00 yellow?

  • Red and green light together look yellow
  • FF means yellow
  • The blue channel represents yellow
  • That is how paints mix
Additive mixing: red + green = yellow.

How many colors do 2 bits per channel give?

  • 6
  • 8
  • 16
  • 64
6 bits in total: 26 = 64. (4 levels per channel: 4 × 4 × 4.)

What sample rate do you need at least to record a 10 kHz sound correctly?

  • 10 kHz
  • More than 20 kHz
  • 5 kHz
  • Exactly 44.1 kHz
Nyquist: more than twice the highest frequency.

What does dropping the bit depth from 16 to 8 affect?

  • The pitch
  • The duration
  • How finely each sample is rounded (noise)
  • The number of channels
Fewer levels → bigger rounding error → audible noise.
