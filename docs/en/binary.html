Binary

The computer’s native language has only two digits. In this chapter you will discover, by playing with bits, how every number can be written with just 0 and 1.

⏱ ~30 minPrerequisite: Number Bases
By the end of this chapter you will
  • be able to explain why computers use binary rather than decimal;
  • convert an 8-bit binary number to decimal in your head;
  • convert decimal to binary by “subtracting powers of two”;
  • add two binary numbers using carries.

Why binary?

A processor contains billions of transistors. Each one acts like a switch: it either conducts (1) or it doesn’t (0). A single 0/1 value — the smallest unit of information — is called a bit (binary digit).

Think first

Why don’t we build computers that use 10 voltage levels and work directly in decimal?

Show answer

Electrical signals are always a bit noisy: temperature, interference and wire length all nudge the voltage. Asking only “high or low?” is far more reliable, faster and cheaper than telling 10 nearby levels apart. Fewer states = fewer errors.

Building numbers from bits

Binary is a place-value system too, just with base 2. From right to left, each bit’s weight doubles: 1, 2, 4, 8, 16, 32, 64, 128. A number’s value is the sum of the weights of the bits that are 1.

Did you notice?
  • Odd numbers always end in 1, because every weight except the 1 is even.
  • Shifting left multiplies by 2 (like appending a 0 in decimal multiplies by 10). Shifting right divides by 2 and drops the remainder.
  • With all bits 1 the value is 2n − 1: 255 for 8 bits. One more (256) needs a 9th bit.

Binary → decimal

Just add the weights of the bits that are 1. You can ignore the 0 bits entirely.

Bit:      1   1   0   1   0   1   1   0
Weight:  128  64  32  16   8   4   2   1
          ↓   ↓       ↓       ↓   ↓
         128 +64     +16     +4  +2   = 214

Decimal → binary: subtract powers of two

The repeated division from the previous chapter always works. For small numbers there is a more intuitive way: start at the largest weight; if it fits into what is left, set that bit to 1 and subtract it, otherwise write 0.

Binary addition and carries

Binary addition is exactly the addition you learned in school; the only difference is that a carry happens as soon as you reach 2. There are four rules:

What if it doesn’t fit in 8 bits?

If the sum of two 8-bit numbers exceeds 255, a carry falls off the left end and does not fit in the 8-bit box. The computer usually drops that 9th bit and the result “wraps around”. In 8 bits, 200 + 100 is not 300 but 44 (300 − 256). This is called overflow. Try 11001000 + 01100100 in the box above! More in chapter 5.

Summary

  • A bit is the smallest unit of information, with two values. Binary is used because hardware can tell two states apart reliably.
  • Bit weights from right to left: 1, 2, 4, 8, 16, 32, 64, 128…
  • Binary → decimal: add the weights of the 1 bits.
  • Decimal → binary: subtract the largest weights that fit (or divide by 2 repeatedly).
  • In addition 1 + 1 = 10₂: write 0, carry 1. A result that doesn’t fit the fixed width overflows.

If you append a 0 to the right of a binary number, what happens to its value?

  • Nothing
  • It is multiplied by 10
  • It doubles
  • It halves
Every bit moves one place left and its weight doubles. This is a left shift (<< 1).

Which of these is definitely odd?

  • 1110
  • 1000
  • 1010
  • 0111
If the rightmost bit is 1 the number is odd: 0111 = 7.

In binary, 1 + 1 + 1 (including a carry): what do you write and what do you carry?

  • Write 0, carry 1
  • Write 1, carry 1
  • Write 1, no carry
  • Write 11, no carry
1 + 1 + 1 = 3 = 11₂ → the right 1 is written, the left 1 is carried to the next column.
