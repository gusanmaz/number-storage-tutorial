Colors & Images

Every dot on your screen is made of three tiny lights, and the brightness of each light is a single byte. In this chapter you will see the maths behind color codes like #FF5733 and how a photo is stored in memory.

⏱ ~35 minPrerequisites: Hex, Bits & Bytes
By the end of this chapter you will
  • be able to explain that screens make colors from red, green and blue light (additive mixing);
  • convert a hex color code to RGB values and back;
  • know how the alpha channel and shades of gray are encoded;
  • understand that images are made of pixels and calculate their raw size.

How does a screen make color?

Look at your phone screen through a magnifying glass and you’ll see that each pixel is really three tiny lights: red, green and blue. As these lights mix, our eyes perceive other colors. Because adding light makes colors brighter, this is called additive color mixing. (Paint is the opposite: mixing makes it darker.)

Three lights, endless colors

Change the brightness of each light. Where two overlap you get yellow, cyan and magenta; where all three overlap, white.

Hex color code: #RRGGBB

Each channel’s brightness is a number from 0 (off) to 255 (fully on) — exactly 1 byte. A byte is written as two hex digits; put three channels side by side and you get a 6-digit color code:

Three channels × 8 bits = 24 bits, i.e. 2²⁴ = 16,777,216 different colors. The human eye can’t tell most of them apart, which is why 24-bit color is called “true color”.

An image is a grid of pixels

    

        A digital image is made of pixels arranged in rows. Memory, however, has no second dimension: pixels are stored
        left to right, top to bottom as one long byte sequence. Each pixel takes 3 bytes (RGB) or 4 bytes (RGBA).

        So why aren’t my photos that big?
        
Formats like PNG and JPEG compress the data. PNG shortens repeating patterns without losing any information (lossless).
        JPEG throws away details the eye won’t notice (lossy) and usually shrinks the file to about a tenth of its raw size. But when the image is drawn,
        it is decompressed back to raw form in memory: a 12-megapixel photo takes about 48 MB of RAM.

    


    
Colors and pixels in p5.js


function setup() {
  createCanvas(200, 200);
  background("#1a1a2e");        // hex string
  fill(255, 87, 51);            // R, G, B (0–255)
  rect(20, 20, 70, 70);
  fill(0, 120, 255, 128);       // 4th value is alpha: semi-transparent blue
  ellipse(110, 110, 100);
  fill(128);                    // a single value = gray (R = G = B)
  rect(130, 20, 50, 50);

  // Change pixels directly: each pixel is 4 bytes (R, G, B, A)
  loadPixels();
  for (let i = 0; i < pixels.length; i += 4) {
    pixels[i + 2] = 255 - pixels[i + 2];   // invert the blue channel
  }
  updatePixels();
}


    

        pixels[] = the image in memory
        
p5.js’s pixels array is the same kind of byte sequence you saw in the pixel editor above: the red byte of pixel (x, y) is at index
        4 × (y × width + x). (On high-density screens pixelDensity() changes this calculation.)

    


    


    

        
Summary

        
    
            
  • Screens make color by mixing red, green and blue light; each channel is 1 byte (0–255).
    • 
            
  • #RRGGBB = 3 bytes = 24 bits ≈ 16.7 million colors. R = G = B means gray.
    • 
            
  • The alpha channel stores transparency; an RGBA pixel is 4 bytes.
    • 
            
  • An image is a byte sequence of pixels laid out row by row. Raw size = width × height × bytes/pixel.
    • 
            
  • File formats (PNG, JPEG) store this data compressed.
    • 
        

    


    

        

            
What color is #00FF00?

            
  • Red
  • Blue
  • Green
  • Black

            
R = 00, G = FF, B = 00 → only the green light is fully on.

        

        

            
What color appears when red and green light mix at full brightness?

            
  • Yellow
  • Brown
  • White
  • Magenta

            
In additive mixing R + G = yellow (#FFFF00). Different from mixing paint!

        

        

            
Which is true about #333333 and #CCCCCC?

            
  • Both are blue
  • #333333 is lighter
  • They are the same color
  • Both are gray, #CCCCCC is lighter

            
R = G = B, so both are gray. 0xCC = 204 > 0x33 = 51.

        

        

            
How many bytes does an uncompressed 100 × 100 pixel RGBA (32-bit) image take?

            
  • 10,000
  • 40,000
  • 30,000
  • 320,000

            
100 × 100 × 4 bytes = 40,000 bytes.

        

        

            
What is the long form of the shorthand #F0A?

            
  • #F0A000
  • #0F0A00
  • #FF00AA
  • #F00A0A

            
Each digit is doubled: F→FF, 0→00, A→AA.
