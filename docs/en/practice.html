Cheat sheet

Everything you need to know in one place. Print it and keep it next to you.

Powers of two

2⁰ = 12⁶ = 64
2¹ = 22⁷ = 128
2² = 42⁸ = 256
2³ = 82¹⁰ = 1,024
2⁴ = 162¹⁶ = 65,536
2⁵ = 322³² ≈ 4.29 × 10⁹

Hex ↔ binary

Conversions

  • b → 10: sum digit × bposition
  • 10 → b: divide by b, reverse the remainders
  • 2 ↔ 16: group in 4s
  • 2 ↔ 8: group in 3s
  • Fraction → 2: multiply by 2, take the integer part

Sizes

  • n bits → 2ⁿ values, 0 … 2ⁿ−1
  • Signed n bits: −2ⁿ⁻¹ … 2ⁿ⁻¹−1
  • N values need ⌈log₂ N⌉ bits
  • 1 byte = 8 bits = 2 hex
  • KiB = 1024 B, kB = 1000 B

Two’s complement

  • Leftmost bit = −2ⁿ⁻¹ (−128 in 8 bits)
  • Negate: flip + 1
  • 11111111 = −1
  • 10000000 = −128

IEEE 754 float

  • 1 sign · 8 exponent · 23 mantissa
  • (−1)ˢ × 1.m × 2^(e−127)
  • double: 1 · 11 · 52, bias 1023
  • 0.1 isn’t exact → compare with a tolerance

Text

  • '0' = 48 = 0x30
  • 'A' = 65 = 0x41
  • 'a' = 97 = 0x61 (A + 32)
  • UTF-8: 1–4 bytes, ASCII-compatible
  • é ü ñ ç → 2 bytes, € → 3, 😀 → 4

Media & memory

  • #RRGGBB = 3 bytes
  • Image = w × h × bytes/pixel
  • Audio = rate × bits/8 × channels × s
  • Nyquist: rate > 2 × frequency
  • address(a[i]) = start + i × size
  • x86/ARM: little-endian
