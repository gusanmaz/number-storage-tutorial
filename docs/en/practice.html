§ 12.2One-page summary

The whole site fits on the cards below.

Powers of two

Decimal · binary · hex

Conversion recipes

  • x → decimal: each digit × baseposition, add up.
  • decimal → x: divide by the base, read remainders bottom to top.
  • binary ↔ hex: group in 4s from the right. binary ↔ octal: 3s.
  • fraction → binary: multiply by 2, take the integer part, repeat.
  • If the denominator is not a power of 2, the binary fraction repeats forever (like 0.1).

Bits, bytes, units

  • n bits → 2n patterns; largest unsigned 2n − 1.
  • To encode N things you need ⌈log₂ N⌉ bits.
  • 1 byte = 8 bits = 2 hex digits.
  • kB = 1000 B · KiB = 1024 B · MiB = 1024² · GiB = 1024³
  • Mbit/s ÷ 8 = MB/s

Floating point (IEEE 754)

(−1)s × 1.m × 2e − bias

  • float: 1 + 8 + 23 bits, bias 127, ≈ 7 digits
  • double: 1 + 11 + 52 bits, bias 1023, ≈ 16 digits
  • Exponent all 1s → ∞ / NaN · all 0s → zero and subnormals
  • 0.1 + 0.2 ≠ 0.3 → compare with a tolerance

Text

  • ASCII 7 bits: '0' = 48 = 0x30 · 'A' = 65 = 0x41 · 'a' = 97 = 0x61
  • upper ↔ lower case: bit 5 (0x20)
  • NUL 0 · TAB 9 · LF 10 (\n) · CR 13 (\r) · space 32
  • UTF-8: ≤ U+007F 1 byte · ≤ U+07FF 2 · ≤ U+FFFF 3 · beyond 4
  • Continuation bytes are 10xxxxxx

Color and media

  • #RRGGBB: 3 bytes; #RRGGBBAA: 4 with alpha
  • Image = width × height × bytes/pixel
  • Sound = samples/s × bits/sample × channels · CD: 44.1 kHz, 16 bit, 2 channels
  • Nyquist: sample rate > 2 × highest frequency

Memory

  • Every byte has an address; addresses are written in hex.
  • Little endian: low byte at the low address (x86, ARM). Big endian: network, PNG.
  • arr[i] = start + i × size · pointer = variable holding an address
  • File type lives in the first bytes: PNG 89 50 4E 47, PDF %PDF, ZIP PK

Code

  • 0b binary · 0o octal · 0x hex · 1_000
  • & select · | set · ^ toggle · & ~ clear · << ×2 · >> ÷2
  • Python int is unbounded; JS number = double (safe to 253), bitwise ops are 32-bit
  • Lists/objects are shared by reference; copy explicitly.
