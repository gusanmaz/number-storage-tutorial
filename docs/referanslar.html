Değişkenler ve Referanslar

C’de bir değişken, belirli bir adresteki kutudur. Python ve JavaScript’te ise değişken, bellekteki bir nesneye bağlanmış bir isim etiketidir. Bu fark, yeni başlayanların en sık takıldığı hataların kaynağıdır.

⏱ ~30 dkÖn koşul: Bellek
Bu bölümün sonunda
  • Python/JS’te bir atamanın (b = a) veriyi kopyalamadığını, referansı kopyaladığını açıklayabileceksin.
  • Değiştirilebilir (mutable) ve değiştirilemez (immutable) türleri ayırt edebileceksin.
  • Bir fonksiyona liste geçirince neden orijinalin değiştiğini anlayacaksın.
  • == ile is / === farkını ve sığ/derin kopyayı bileceksin.

Kutu mu, etiket mi?

C: değişken = kutu

int a = 10; int b = a; → iki ayrı kutu, ikisinde de 10 yazıyor. b’yi değiştirmek a’yı etkilemez. Bir önceki bölümde gördüğün gibi her değişkenin sabit bir adresi var.

Python / JS: değişken = etiket

Değerler (nesneler) bellekte bir yerde durur. Değişken sadece o nesneye bağlı bir isimdir; içinde nesnenin adresi (referansı) vardır. b = a → yeni nesne yok; aynı nesneye ikinci bir etiket.

Bu her zaman sorun yaratmaz. Sorun, nesne yerinde değiştirilebiliyorsa başlar. Aşağıdaki izleyicide her senaryoyu adım adım çalıştır. Bazı adımlarda sonuca bakmadan önce tahmin etmen istenecek.

Referans izleyici

isim (değişken) nesne (bellekte) artık kimse göstermiyor → çöp toplayıcı siler

Değiştirilebilir ve değiştirilemez türler

Değiştirilemez (immutable)

Python: int, float, bool, str, tuple, None
JS: number, string, boolean, null, undefined, bigint

Nesne bir kez oluştu mu değişmez. a = a + 1 yeni bir nesne yaratır ve a etiketini oraya taşır. Bu yüzden paylaşmak güvenlidir.

Değiştirilebilir (mutable)

Python: list, dict, set, kendi sınıfların
JS: Array, Object, Map, Set

append, push, x[0] = … gibi işlemler nesneyi yerinde değiştirir. O nesneye bağlı bütün isimler değişikliği görür.

Sık yapılan hata: “kopyaladım” sanmak

yedek = liste bir yedek almaz! İki isim aynı listeyi gösterir. Gerçek kopya için Python’da liste.copy(), list(liste) ya da liste[:]; JavaScript’te [...dizi] ya da structuredClone(nesne) kullan.

== ile is (ve ===)

Eşitlik (==) iki nesnenin içeriğinin aynı olup olmadığını sorar. Kimlik (Python’da is) ise iki ismin aynı nesneyi gösterip göstermediğini, yani adreslerin aynı olup olmadığını sorar.

a = [1, 2]
b = [1, 2]
c = a
print(a == b)      # True   içerikler aynı
print(a is b)      # False  farklı nesneler
print(a is c)      # True   aynı nesne
print(id(a), id(c))  # aynı sayı: nesnenin kimliği (CPython'da bellek adresi)

if x is None:      # None kontrolü her zaman "is" ile yapılır
    ...

const a = [1, 2];
const b = [1, 2];
const c = a;
console.log(a === b);   // false  nesnelerde === kimliği karşılaştırır!
console.log(a === c);   // true
console.log(5 === 5);   // true   ilkel türlerde değer karşılaştırılır

// İçerik karşılaştırmak için (basit durumlar):
JSON.stringify(a) === JSON.stringify(b);   // true
Sayıları is ile karşılaştırma

CPython, −5 ile 256 arasındaki küçük tamsayıları önceden oluşturup paylaşır. Bu yüzden a = 100; b = 100; a is b çoğu zaman True çıkar, ama büyük sayılarda sonuç kodun nasıl çalıştırıldığına göre değişebilir. Bu bir uygulama ayrıntısıdır: değerleri her zaman == ile karşılaştır.

const değişmez demek değildir

JavaScript’te const, ismin başka bir nesneye bağlanamayacağı anlamına gelir; nesnenin kendisi değiştirilebilir.

const sepet = ["elma"];
sepet.push("armut");     // ✓ çalışır: aynı dizi, yerinde değişti
sepet = ["muz"];         // ✗ TypeError: isim yeniden bağlanamaz
Object.freeze(sepet);    // gerçekten değiştirilemez yapmak için (sığ)

Özet

  • Python/JS’te değişkenler nesnelere bağlı isimlerdir; atama referansı kopyalar, nesneyi değil.
  • Değiştirilemez nesneler (sayı, metin) “değişince” aslında yeni nesne oluşur.
  • Değiştirilebilir nesneler (liste, sözlük, dizi, obje) yerinde değişir; o nesneyi gösteren her isim değişikliği görür.
  • Fonksiyona geçirilen liste kopyalanmaz; fonksiyon onu değiştirebilir.
  • == içerik, is / nesnelerde === kimlik karşılaştırır. Sığ kopya iç içe nesneleri hâlâ paylaşır.

x = [1, 2]; y = x; y.append(3); print(x) ne yazdırır?

  • [1, 2]
  • [1, 2, 3]
  • [3]
  • Hata
x ve y aynı listeyi gösteriyor; append listeyi yerinde değiştirir.

s = "kedi"; t = s; s = s + "ler"; print(t) ne yazdırır?

  • kedi
  • kediler
  • ler
  • Hata
Metinler değiştirilemez. s + "ler" yeni bir nesne oluşturur; t eski nesneyi göstermeye devam eder.

JavaScript’te [1] === [1] sonucu nedir?

  • true
  • Hata
  • false
  • undefined
İki ayrı dizi nesnesi oluşturuldu; === nesnelerde kimliğe bakar.

a = [[0], [0]]; b = a.copy(); b[0].append(1) sonrasında a nedir?

  • [[0], [0]]
  • [[0, 1], [0, 1]]
  • [[0], [0], 1]
  • [[0, 1], [0]]
copy() sığ kopyadır: dış liste yeni, ama içteki listeler paylaşılıyor.

Bir fonksiyonun, kendisine verilen listeyi değiştirmeden yeni liste döndürmesi için en iyi yol hangisi?

  • Parametreye yeni değer atamak
  • Listenin kopyası üzerinde çalışıp onu döndürmek
  • global kullanmak
  • is kullanmak
Örneğin yeni = lst.copy(); yeni.append(x); return yeni. Böylece çağıranın listesi bozulmaz.
